Hãy đóng vai một Senior Backend Developer. Tạo cho tôi một ứng dụng backend cơ bản bằng Python FastAPI. Ứng dụng này sẽ làm API gateway kết nối với mạng xã hội.
Yêu cầu:

Khởi tạo cấu trúc thư mục chuẩn cho dự án FastAPI.

Tạo file requirements.txt chứa các thư viện cần thiết (bao gồm fastapi và uvicorn).

Tạo một endpoint (đường dẫn) POST ở route /api/v1/scan nhận vào một payload JSON đơn giản. Tạm thời endpoint này chỉ cần trả về HTTP status 200 và chuỗi thông báo 'Scanning sequence initialized...'.
Hãy tự động tạo file và cập nhật mã nguồn vào thư mục làm việc.
